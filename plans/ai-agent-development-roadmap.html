AI Agent Development

Your 14-week roadmap · seven phases · six shipped projects · Python basics assumed · 10–20 h / week

AbstractThis roadmap takes you from Python basics to career-ready agent-engineering skill: by week 14 you can design, build, evaluate, and deploy LLM agents — backed by a GitHub portfolio of 5+ projects and the fundamentals to handle AI-engineer interviews. Fourteen weeks, seven phases, every phase ending in a shipped repo, because employers hire on evidence, not certificates. Prepared July 2026. The field moves fast — if you're reading this months later, re-verify tools and links.

§1

Why this plan is shaped the way it is

Principle 1

Fundamentals before frameworks

Anthropic's guidance for builders is to start with direct LLM API calls — most agent patterns are a few lines of code, and frameworks add abstraction that hides what's actually happening. Interviews probe fundamentals, so you'll build the agent loop from scratch before touching LangGraph.

Principle 2

One shipped project per phase

Employers hire on evidence, not certificates. Everything goes on GitHub — six projects by week 14, each one a repo someone else can clone, run, and judge.

Principle 3

Evaluation is the career differentiator

Anyone can demo an agent; few people can make one reliable. Phases 5–6 are where you separate from the crowd.

Principle 4

Simplest thing that works

A large share of real-world "agent" tasks are actually solved by a single well-prompted LLM call with structured output. Knowing when not to build an agent is itself a job skill.

ph-0setup week 1

Toolkit & Python leveling

A professional dev setup and the specific Python you'll use constantly.

  • Git + GitHub: init, commit, branch, push, and writing a README.
  • Environments: uv (modern, fast) or venv + pip; VS Code; a .env file with python-dotenv for API keys — never commit keys.
  • Python essentials for agent work: functions and type hints, dicts and JSON handling, error handling with try/except, classes and dataclasses, Pydantic models, async/await basics, HTTP calls with httpx.
  • Get an API key (Anthropic Console and/or OpenAI) and understand tokens and pricing so costs never surprise you — use the cheapest model tier while learning.

ph-1track A weeks 2–3

LLM & API foundations

Total comfort with the raw ingredients every agent is made of.

  • Chat structure: system vs. user vs. assistant messages; the API is stateless — you manage conversation history.
  • Sampling controls: temperature, max tokens, and when to use temperature 0; streaming responses.
  • Prompt engineering: clear instructions, few-shot examples, structured/XML prompts, giving the model room to reason.
  • Structured output: requesting JSON, validating with Pydantic, retrying on invalid output — this pattern alone powers a huge share of production systems.
  • The model landscape: capability tiers vs. price; develop on cheap models, test on strong ones.
  • Intuition for what's under the hood — pick one: 3Blue1Brown's neural-networks/Transformer series or Karpathy's "Intro to Large Language Models."
Ship → Project 1A CLI chat assistant: multi-turn memory, streaming, switchable system-prompt personas, a /save command for transcripts, and a running token/cost meter. Stretch goal: when history gets long, summarize older turns and keep the summary in context.
Checkpoint — you canManage conversation history by hand · reliably get valid JSON from a model · estimate what 1,000 user queries would cost.

ph-2track A weeks 4–5

Tool use & the agent loop — from scratch

The heart of the entire plan: an agent is just an LLM in a loop, with tools, working toward a goal. Build that loop yourself once and no framework will ever be magic to you.

  • Tool use (function calling): defining tool schemas, letting the model request a call, executing it in your code, returning the result to the model.
  • The agent loop: call model → if it requests a tool, run it → append result → call model again → stop when the task is done or max iterations hit.
  • Read "Building Effective Agents" (Anthropic) — twice. Internalize the core distinction: workflows (prompt chaining, routing, parallelization, orchestrator–workers, evaluator–optimizer) vs. agents, and the advice to use the simplest pattern that works.
  • ReAct — the 2022 paper that named the reason-then-act pattern; skim for grounding.
  • Failure handling: malformed tool calls, tool errors, runaway loops, timeouts, max-iteration guards.
Ship → Project 2A research agent, zero frameworks. Tools: web search (Tavily or Brave Search API have free tiers), calculator, and file read/write. It should handle questions like "Compare the populations of Japan's three largest cities and save a summary to a file." Include a max-iteration guard and print a readable trace of every step it takes.
Checkpoint — you canWhiteboard the agent loop from memory · explain when a workflow beats an agent · name the five workflow patterns with a use case for each. This checkpoint is interview gold.
Materials
  • readBuilding Effective Agents — Anthropic — twice; the spine of this phase
  • workTool use guide + anthropic-cookbook examples — schemas and the loop, in code
  • readOpenAI — A Practical Guide to Building Agents — free PDF

ph-3track A week 6

RAG, memory & context engineering

Give agents knowledge they weren't trained on — and manage their limited attention.

  • Embeddings and similarity search; chunking strategies; a local vector store (Chroma is the easiest start).
  • The RAG pipeline: ingest → embed → retrieve → insert into prompt → answer with citations.
  • Agentic RAG: retrieval as a tool the agent decides when to call.
  • Memory patterns: rolling summaries for short-term; files or a small database for long-term.
  • Context engineering: deciding what goes into the context window and what stays out — read Anthropic's engineering posts on effective context engineering and on writing effective tools for agents.
Ship → Project 3"Chat with your docs." Ingest a folder of PDFs/markdown in a domain you know well, answer questions with citations to source chunks, then plug retrieval in as a tool on your Phase 2 agent.
Checkpoint — you canExplain chunk-size tradeoffs · describe two ways RAG fails and why.
Materials
  • readAnthropic engineering blog — the context-engineering and tool-writing posts
  • workChroma getting started — your first local vector store
  • doA DeepLearning.AI RAG short course — audit free
ph-4track B weeks 7–9

Frameworks & MCP

Now that you know what frameworks abstract away, learn the ones the job market actually uses.

  • LangGraph (weeks 7–8) — the current production standard for stateful agent orchestration: graphs, nodes and edges, state, checkpointing/persistence, human-in-the-loop interrupts, streaming. Do LangChain Academy's free "Introduction to LangGraph."
  • MCP — Model Context Protocol (week 9) — the open standard for connecting agents to tools and data; think USB-C for AI integrations. Every major framework now supports it. Build a server exposing 2–3 custom tools and connect it to Claude. Anthropic Academy's MCP courses walk this end-to-end in Python, including the three primitives: tools, resources, prompts.
  • Survey the landscape (a half-day each, breadth for interviews): OpenAI Agents SDK, Claude Agent SDK, CrewAI, Pydantic AI. Know each one's sweet spot; you don't need mastery.
  • Multi-agent patterns: orchestrator–workers, subagents for context isolation.
Ship → Projects 4a + 4b4a: rebuild your research agent in LangGraph with persistent checkpoints and a human-approval interrupt before any file write. 4b: a custom MCP server for something personal — your notes, a hobby API, your work domain. MCP servers make excellent portfolio pieces because other people can actually plug them into their own agents.
Checkpoint — you canExplain what LangGraph checkpointing gives you over your hand-rolled loop · describe MCP's client–server architecture and its three primitives.
Materials
  • workLangChain Academy — Introduction to LangGraph — free
  • readLangGraph docs — state, checkpointing, interrupts
  • workMCP spec and tutorials — the standard itself
  • workAnthropic Academy MCP courses — server building end-to-end in Python
  • workHugging Face AI Agents Course — free, beginner-to-expert, covers smolagents/LlamaIndex/LangGraph, optional certificate; good parallel track
ph-5track C weeks 10–11

Evaluation, observability & guardrails

The career differentiator: demos are easy; reliability is what gets hired.

  • Tracing: instrument your agent with LangSmith (free tier, deepest LangGraph integration) or Langfuse (open-source, self-hostable) so you can see every step, token, and dollar.
  • Building an eval set: 25–50 real test cases with expected outcomes, graded by exact match, rubric, or LLM-as-judge.
  • Regression testing: re-run evals on every prompt or model change; track pass rates over time.
  • Agent-specific metrics: task success rate, tool-selection accuracy, steps-to-completion, cost per task.
  • Guardrails: prompt injection (treat untrusted content as data, never instructions), tool permissioning, sandboxing, human approval for irreversible actions.
  • Cost and latency: prompt caching, model routing (cheap model for easy steps).
Ship → Project 5Add tracing plus a ~30-case eval suite to your Phase 4 agent. Deliberately break it — ambiguous requests, adversarial inputs, failing tools — measure, fix, re-measure. Write an EVALS.md documenting the before/after numbers. This document impresses interviewers more than the agent itself.
Checkpoint — you canExplain LLM-as-judge and its pitfalls · describe a prompt-injection attack against your own agent and how you mitigated it.
Materials
  • workLangSmith · Langfuse — both have solid evaluation guides; pick one and instrument
  • doA DeepLearning.AI agent-evaluation short course — audit free
  • readOWASP Top 10 for LLM Applications — the threat catalogue your guardrails answer
ph-6track Atrack Btrack C weeks 12–14

Capstone & career packaging

One substantial, deployed, documented project plus a portfolio that gets interviews — ideally in a domain you already know, because domain knowledge + agents is your edge over CS grads.

Pick one capstone
  • Customer-support agent over a product's docs, with escalation/handoff logic.
  • Personal ops agent: email triage → drafted replies, calendar-aware.
  • Data-analysis agent: CSV in → cleaned data, charts, and a written report out.
  • Code-review or documentation agent for a GitHub repository.
Ship → The bar that reads as "professional"Deployed: a FastAPI backend + minimal web UI, or a Slack/Discord bot · a README with an architecture diagram and a "why these design choices" section · an eval-results table and example traces · a 2–3 minute demo video · costs documented — what do 1,000 requests cost?
Career moves — run in parallel
  • Pin your 3 best repos; polish every README.
  • Write 2–3 posts (LinkedIn or a blog): "What I learned building X" — hiring managers genuinely read these.
  • Target titles: AI Engineer · Agent Engineer · Forward-Deployed Engineer · Solutions Engineer (AI) · LLM Application Developer.
  • Interview prep themes: agent-vs-workflow design decisions, cost/latency tradeoffs, eval design, failure modes, RAG design, "how would you build X" system design.
  • Make one small open-source contribution to an agent tool (docs PRs count) — great interview conversation material.

How we'll work together

Use Claude as your always-available tutor. A cadence that works:

  • Start of each week. "I'm on Week N of my agent roadmap — teach me [topic]." Claude explains it, checks your understanding, and sets the exercise.
  • Mid-week. Paste your code and ask for a review — critiqued like a senior engineer would: bugs, design, style.
  • Stuck for more than ~30 minutes? Bring the error and what you've tried. (Struggle a little first; that's where the learning lives.)
  • End of each week. "Quiz me on Week N's checkpoint" before moving on.
One honest warning from your tutor: let AI explain and review, but type the code yourself through at least Phase 3. If Claude writes your agent loop for you, you'll freeze when an interviewer asks you to whiteboard it.
